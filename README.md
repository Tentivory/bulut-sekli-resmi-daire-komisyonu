# T.C. Bulut Şekli Resmi Daire Komisyonu

**Karar sayısı:** 2026/BŞRDK-001  
**Konu:** Gökyüzündeki şekillerin tasnifi, mühürlenmesi ve arşivlenmesi.

Bu yazılım, balkonunuzdan baktığınızda "aa bu koyun gibi" dediğiniz şeyi alıp resmi bir karar metnine çevirir. Karar kesinleşir. İtiraz süresi üç iş günüdür; üçüncü günün sonunda bulut zaten gitmiş olur.

## Neden var?

Çünkü gökyüzü başıboş bırakılamaz. Bir şey resmi evraka dönüşmeden duramaz. Komisyon kuruldu, çaylar geldi, mühür ısıtıldı.

## Kuruluş

```bash
python3 komisyon.py
```

Python 3 yeter. Ek paket yok. Devlet tasarruf tedbirleri gereği `pip` kullanılmadı.

## Kullanım

Program size gökyüzünde ne gördüğünüzü sorar. Boş bırakırsanız komisyon re'sen gözlem yapar. Çıktı şuna benzer:

- Karar numarası
- Resmi ad (örneğin "devrilmiş semaver")
- Gerekçe (genelge, çay molası, güneş açısı)
- SHA tabanlı mühür
- Dipnot

## Bilimsel dayanak

Yok. Ama cümleler resmi olduğu için bilimsel görünür. Bu yeter.

## Katkı

Pull request açabilirsiniz. Komisyon her PR'yi "görüşülmek üzere gelecek oturuma" alır. Gelecek oturum tarihi belirsizdir.

## Sorumluluk reddi

Bu yazılım meteoroloji değildir. Uçak kullanmayın. Şemsiye kararını kendiniz verin. Hiçbir siyasi parti, resmi kurum veya semaver üreticisi bu projeyi desteklememektedir.
